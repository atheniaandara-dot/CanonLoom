# Community conduct

Treat writers and developers with respect, including beginners. Discuss ideas without personal attacks. Do not harass people, publish their private information, or copy their unpublished writing into issues without permission.

Use minimal fictional examples when reproducing problems. Creative work can cover difficult themes; keep technical discussions focused on behavior, data, and reproducible bugs.

Maintainers may edit or remove material that violates these expectations, close disruptive discussions, or restrict participation. Enforcement should be proportionate and explained when possible. For a concern, contact a repository maintainer using an available private GitHub contact route; do not publish sensitive details in an issue. No dedicated private reporting address is configured for this initial release.
