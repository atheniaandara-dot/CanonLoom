# CanonLoom 0.1.0 — Keep the thread

The first preview of a local-first continuity engine for novelists and AI roleplay writers.

## Included

- Offline app with English and Indonesian interface labels.
- Story bible for characters, places, items, and world information.
- Structured scene claims and explicit changes with provenance.
- Contradiction, knowledge, locked-fact, rule, and timeline checks.
- Isolated drafts and atomic canon commits.
- JSON backup/import and director/character Markdown context export.
- JavaScript API, CLI, JSON Schema, original sample stories, tests, and English documentation.

## Downloads

- `CanonLoom-0.1.0.html`: self-contained browser app. Open in a modern browser.
- `canonloom-0.1.0.tgz`: installable JavaScript package and CLI.
- `SHA256SUMS.txt`: checksums for the two assets above.
- GitHub's source archive: full repository, including tests and maintainer documentation.

No AI key, account, or subscription is needed. On phones that cannot run a downloaded HTML file, use a hosted app in a regular browser.

## Known limits

The checker compares structured facts; it does not automatically understand prose. Exact values matter. Storage is local and unencrypted, with one open workspace and one previous-save recovery point. Export backups regularly. Branching, cloud sync, and prose extraction are not included. This is a preview; report small reproducible problems rather than sharing private manuscripts.

This release makes no claims about existing users, stars, contributors, or popularity.
