# Roadmap

These are proposed directions, not shipped features or promised delivery dates.

## Next: make everyday editing safer

- Named project selection and a recoverable version history.
- Search across facts and scene events, not only entity notes.
- Better explanations and guided fixes for invalid entity references.
- More translated diagnostics and assistive-technology testing.
- Measured performance budgets for long projects and incremental replay.

## Later: richer story structure

- Explicit branches and alternative drafts with a versioned timeline model.
- Optional travel-duration constraints and scene intervals.
- Fact confidence, author citations, and accepted contradictions with documented scope.
- Adapters for writing tools using the portable schema.

## Optional AI assistance

- Extract proposed events from prose for review, retaining the exact supporting passage.
- Never silently treat extracted statements as canon.
- Keep provider choice, cost, and transmission of private text explicit.
- Preserve the fully offline workflow.

Useful early contributions include real, anonymized continuity mistakes, accessibility reports, and small examples from writing workflows. No adoption numbers or community milestones are assumed.
